# Pricing Comparison Table

A responsive pricing comparison page built with semantic HTML and CSS.

This project compares three subscription plans using a real HTML table. I first focused on an accessible table structure, then added CSS styling to make the comparison clean and easy to read.

## Features

- Semantic page structure using `header`, `main`, and `footer`
- Real HTML table with `caption`, `thead`, and `tbody`
- Three subscription plans: Starter, Pro, and Team
- Column and row header scopes for accessibility
- Merged feature-section rows using `colspan`
- Responsive table container for smaller screens
- Green styling with hover effects

## Built With

- HTML5
- CSS3

## Accessibility Practices

- Descriptive table caption
- `scope="col"` for column headers
- `scope="row"` for row headers
- `scope="rowgroup"` for feature categories
- Semantic table structure for screen-reader context

## What I Practiced

- When to use an HTML table for structured data
- Table headings, captions, and scopes
- `colspan` and `rowspan`
- Responsive table layouts
- Styling accessible tables with CSS
